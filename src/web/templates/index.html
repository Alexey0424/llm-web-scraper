LLM Web Scraper
methodology vanilla-base idle {{ record_count }} records

Discover records from any site

Give a URL and a plain-language prompt naming the fields you want. A local LLM plans the crawl, walks the site, and extracts the records into a table whose columns match your prompt.

Mode

Sites run one after another. Results combine into one stacked Excel with a “Site” column showing where each row came from.

Each operation has its own prompt and runs in order, one finishing before the next starts. Results combine into one workbook, one sheet per operation.
